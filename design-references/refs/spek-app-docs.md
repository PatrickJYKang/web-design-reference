## Read
- One size carries nearly everything: 13px/1.7 for 96% of the text, 15px w500 for section labels, 26px w600 for the h1. Inside a card, title and description differ only by weight and colour (#0e0e10 against #6c6c76).
- The index is a wall of equal cards: about 242×255, 12px apart, radius 12px, fill #fbfbfa on white, four to a row in a 1002px grid. Each has an outline icon top-left, then a title and two lines of description pushed to the bottom.
- Eight labelled groups of cards follow the seven collapsed groups in the sidebar, with a list of questions last; the intro holds a 720px measure while the grids run wider.
- Almost no chrome or colour: no shadows, borders at 5% black, and the #0051ff sign-in pill as the only hue.

## Weak spots
- More than half of each 255px card is empty, so about 30 links take 4.9 screens at desktop and 12.2 on a phone.
- The first group repeats four pages that appear again in the groups below.
